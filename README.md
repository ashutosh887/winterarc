# winterarc

Lock in while they coast. ❄️  
*Disappear for 90 days. Come back unrecognizable.*

Open source WinterArc tracker — Oct 1 → Dec 31 (92 days, Jan 1 graduation). Local-first, PWA, no login.

**Live:** https://winterarc-khaki.vercel.app

## Features
- 92-day grid — backfill, no restart
- 3-tier habits + templates & resources (`src/config.ts`)
- Rings, quotes (120), achievements, share (X/WA/PNG)
- Export JSON/CSV + LLM prompt
- PWA offline

## Stack
Vite + React + Tailwind + PWA + Framer Motion + Three.js

## Getting started
```bash
npm install
npm run dev
npm run build
```

## Config
Edit `src/config.ts` for templates, resources, quotes.
