## Research Insights
- 3-5 habits ideal, binary yes/no, attach time+place, minimum version survives bad days
- Self-selected habits > assigned
- One missed day doesn't break habit curve; 3 unlogged days/week = real fail condition (consider adding)
- Winter costs ~18 min light activity/day (cold/dark) → habit should survive indoors

## X Growth Hooks
- Share card is X-optimized 1200x675
- Achievements are static → everyone chases same badges, viral comparison
- Daily quote gives reason to screenshot daily
- Open source + local-only = trust, easy retweet
